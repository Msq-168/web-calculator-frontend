# Code Style
This project follows Airbnb JavaScript Style Guide.
Reference: https://github.com/airbnb/javascript

## Conventions
### Naming
- JS Variables and functions: lowerCamelCase, e.g. `loadHistory`, `calcEqual`
- Constants: UPPER_SNAKE_CASE
- CSS class names: kebab-case, e.g. `calculator`, `history-area`
- Class names: UpperCamelCase (not used in this project)

### Indentation
- Use 2 spaces for indentation.

### Quotes
- Use double quotes `"` for JavaScript strings and JSON.

### Semicolons
- End each JS statement with semicolons.

### Error Handling
- Fetch use try-catch block for network exception.

### Comment
- Write concise comments for complex logic. Avoid redundant comments.
